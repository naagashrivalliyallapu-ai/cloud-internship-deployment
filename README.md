# CloudSpace – Cloud Computing Internship Project

## Introduction

Cloud computing is a technology that provides computing resources and services such as storage, networking, servers, and application hosting over the internet. It helps developers build, deploy, and manage applications without maintaining physical infrastructure.

As part of my **Cloud Computing Internship at SWYNEX Technologies**, I worked on a project called **CloudSpace**, a static website developed using HTML and CSS and deployed using GitHub Pages.

The project helped me understand the fundamentals of cloud architecture, website hosting, deployment workflows, monitoring, cost awareness, and security practices.

Throughout the internship tasks, I explored how to design a basic cloud architecture, deploy a website, verify deployment using GitHub Actions, and document monitoring and security considerations.

## Project Objectives

- Understand the fundamentals of cloud computing.
- Design a basic cloud architecture for a web application.
- Develop and deploy a static website using GitHub Pages.
- Understand deployment status and monitoring using GitHub Actions.
- Identify basic cost-management practices.
- Understand HTTPS and repository access control.
- Gain practical experience in cloud deployment.
